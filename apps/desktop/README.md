# Prism 앱 (Windows, v0.9.85)

롤 클라이언트 옆에 켜두는 도우미. 혼자 써도 쓸모 있고, Prism 회원이면 모임 기능이 열린다.
웹(przm.web.app)과 같은 화면 코드(`packages/ui`, `packages/core`)를 앱 안에 묶어 넣는다. 원격 웹을 띄우지 않는다.

## 화면
| 탭 | 혼자서도 | Prism 로그인 후 |
|---|---|---|
| 게임 | **챔프 선택**: 우리 팀 구성(AP/AD·앞라인·CC), 부족한 점, 대기석 추천(팀 밸런스·내가 잘하는 순), 챔피언 카드(내 승률·팀에 넣으면·어울리는 증강). **게임 중**: 내 챔피언 **증강 3개 비교**·등급별 가이드 (Alt+Tab). **평소**: 최근 10판, 최근 판, 승률·연승 | 모임 승률 정렬, 같은 팀 회원과의 케미, 장인 |
| 증강 | 챔피언별 가이드, 3개 비교, 증강 도감 | Prism 실전 승률 |
| 모임 | 디스코드·카카오톡 바로가기 (사이드바) | **같이 할 판 모집**(시간·5자리·원탭 참여), **내전**(10자리·팀 나누기·결과 자동), 한 줄 생각, 모임 보드 |
| 설정 | 윈도우 시작 시 실행, 확인용 정보 복사 | 로그인, 수집 동의·철회, 저장 상태 |

챔프 선택이나 게임이 시작되면 앱이 게임 탭으로 바뀐다.

0.7.1부터: 모임 화면에 포텐 멤버(같이 3판 넘게 했거나 내전을 함께한 비회원, 초대 링크 복사). 챔피언 증강 가이드·도감을 원형 아이콘·S~D 티어·이유 설명으로 통일, 챔피언 목록에 역할 필터와 내 판수·승률.

0.7.0부터: 창 제목 "Prism - 0.7.0". 롤이 꺼져 있어도 최근 판은 Prism 에 저장된 내 판으로 보이고, 게임이 없으면 오늘의 챔피언과 어울리는 증강을 추천한다.

0.6.9부터: 버전은 창 제목과 설정에서, 뒤로·앞으로는 사이드바 머리에. 게임이 없으면 게임 화면 맨 위에 "현재 진행 중인 게임이 없습니다"와 다음 모임 판.

0.6.8부터: 켤 때 로딩 화면(빛이 프리즘을 지나 갈라짐, `src/Splash.tsx`), 위쪽 뒤로·앞으로 버튼, 화면 전환 효과. 사이드바 아래 한 칸에 내 얼굴(대표 스킨)·롤 연결 상태·설정 버튼. 화면 테마(시스템/라이트/다크)는 설정에서. 최근 판은 접으면 카드 띠, 펼치면 자세히 (아이템에 마우스를 올리면 능력치·효과, `items-detail.json` 은 처음 올릴 때만 불러온다). 롤을 "테두리 없는 창 모드"로 두면 Alt+Tab 이 빠르다.

## 구조
```
apps/desktop/
  src/            화면 (React). controller.ts = 확인 주기·전적·챔프 선택·업로드 흐름
  src/bridge.ts   Rust 명령 호출 (앱 안: Tauri invoke / 개발 중 브라우저: dev-bridge)
  src-tauri/      Rust (얇게)
    lcu.rs        롤 클라이언트 읽기. 허용 경로만 GET, 게임 실행 중이면 거부
    server.rs     Prism 서버 중계. 로그인 토큰은 여기에만 있고 화면에는 안 나간다
    lib.rs        트레이, 한 번만 실행, 자동 실행(--background), 창 닫기 = 숨기기
  dev-bridge.mjs  개발용 모의 클라이언트 (배포 앱에 안 들어감)
```

## 지키는 것 (CLAUDE.md v3.1-4·5, v3.3)
- 롤 클라이언트는 **읽기(GET)만**, 허용 경로 5개만 (`lcu.rs` 의 `ALLOWED`). 초대·수락·픽 같은 조작 요청은 코드에 없다
- **게임 중에는 롤에 아무 요청도 하지 않는다.** OS 프로세스 목록으로 게임 실행 여부만 본다 (Rust 에서 한 번 더 막는다)
- 게임 프로세스·메모리·인게임 API·오버레이 없음
- **첫 화면에서 디스코드 로그인 → 롤 클라이언트 → 수집 동의를 마쳐야 앱을 쓸 수 있다** (0.6.5부터). 그 전에는 다른 화면·게임 위 작은 창이 열리지 않고 서버로 판을 보내지 않는다. 설정에서 동의를 철회하면 다시 첫 화면으로 돌아간다
- 동의하면: 내 아수라장 판(10명 상세)을 올리고, 한가할 때(대기·로비) 30분에 1번 동의한 다른 회원의 최근 20판을 대신 올린다. 챔프 선택이나 게임이 시작되면 즉시 멈춘다
- 비회원은 회원과 같은 팀이었거나 사용자 설정(내전) 판을 함께했을 때만 '포텐 멤버' 후보로 남고(회원 전용 화면), 가입·동의하면 본인 기록으로 옮겨진다. 그 밖의 비회원 정보는 버린다 (CLAUDE.md v3.10)
- 로그인 토큰은 앱 설정 폴더(`%APPDATA%\gg.przm.desktop\config.json`)에만 저장한다

## 게임 중 증강 자동 인식 (0.6.0부터, CLAUDE.md v3.5)
- 게임 창이 맨 앞일 때만 1.2초마다 화면 가운데(가로 8~92%, 세로 10~72%)를 복사해 Windows 내장 한국어 문자 인식으로 읽고, 증강 이름과 대조한다 (`src-tauri/src/vision.rs`, `matcher.rs`)
- 카드가 보이는 동안에는 0.35초마다 제목 줄만 좁게 읽어 새로고침을 바로 따라간다 (못 찾으면 다시 넓게)
- 카드 2장 이상을 찾으면 게임 위 작은 창(`overlay.html`)에 내 챔피언(챔프 선택 때 기억) 기준 순서와 **어울림 티어 S~D**를 띄운다 (0.6.6부터). 같은 티어이고 점수 차가 8 이내면 같은 순위로 묶고 "취향대로 고르세요"라고 알린다 (`packages/core/src/synergy.ts` `rankFits`). 0.6.7부터 줄마다 **왜 맞는지**(챔피언 기준)와 **언제 더 좋은지**(증강 설명 원문에서 찾은 상황)를 쓰고(`explainFit`), S 티어 실버는 "골드급", S 티어 골드는 "프리즘급"으로 표시한다 (`gradeUp`). 작은 창 크기 420×540 (바탕 투명·클릭 통과). 앱 본 창의 "증강 3개 비교"도 자동으로 채워진다
- 작은 창은 클릭 통과·포커스 안 가져감·녹화 제외. 롤은 **테두리 없는 창 모드**여야 보인다 (전체 화면 독점 모드는 캡처·창 표시가 안 됨)
- 한국어 문자 인식은 Windows 의 한국어 언어팩이 있어야 한다 (한국어 Windows 는 기본 포함)
- 설정 → **찍은 화면으로 시험**: 증강 화면을 Win+Shift+S 로 찍은 뒤 누르면 클립보드 그림을 같은 방식으로 읽어 결과와 읽은 글자를 보여준다 (영역·인식률 맞출 때 사용)
- 캡처한 그림은 저장·전송하지 않는다. 게임 프로세스·메모리·입력은 건드리지 않는다

## 앱 안에서 업데이트 (0.5.3부터)
- 켜질 때(5초 뒤)와 6시간마다 Prism 서버 `/app/latest` 로 최신판을 확인한다 (0.8.6부터. 서버가 GitHub Release 를 대신 내주므로 저장소를 비공개로 돌려도 된다. 서버 주소가 없는 개발 빌드만 GitHub 를 직접 본다)
- 새 버전이 있으면 사이드바에 "새 버전 · 업데이트" 알림, 설정 → 버전에도 버튼
- 누르면 `Prism-Setup.exe` 를 받아 크기·실행 파일 여부를 확인하고, 설치 프로그램을 `/P /R` 로 실행한 뒤 앱을 끈다
  (`/P` 진행 창만 보이는 자동 설치, 실행 중인 Prism 은 설치 프로그램이 닫음 / `/R` 설치 후 다시 실행)
- 받는 주소는 Prism 서버의 `/app/download/` 로만 허용 (`src-tauri/src/update.rs`, 서버 `server/src/release.ts`)
- 0.5.2 이하에는 이 기능이 없어서 0.5.3 은 한 번 직접 받아 설치해야 한다

## 설치 파일 만들기
GitHub Actions `build-desktop` (Windows). 회원 서버 주소는 Variables `PRISM_SERVER_URL`, 없으면 Cloudflare 계정에서 찾아 앱에 넣는다 (서버가 없으면 모임 기능 없이 가이드만).
- 태그 `app-v0.5.0` 을 올리면 GitHub Release 에 `Prism-Setup.exe` 가 붙는다. 회원·웹은 Prism 서버를 거쳐 받는다:
  - 최신판 `{서버}/app/download` (웹의 "앱 받기")
  - 버전 고정 `{서버}/app/download/app-v0.8.6/Prism-Setup.exe` (스토어 등록처럼 바뀌지 않는 주소가 필요할 때)
  - 저장소가 비공개면 Secrets `RELEASE_TOKEN`(이 저장소 Contents 읽기 전용 토큰)을 넣고 deploy-server 를 다시 돌린다
- 또는 Actions 탭 → build-desktop → Run workflow ("릴리스로 공개" 켜짐) → 버전(`tauri.conf.json`)으로 태그와 Release 를 만든다. 끄면 Artifacts 로만 남는다
- 새 버전을 낼 때는 `tauri.conf.json` 의 `version` 을 올린 뒤 실행한다 (같은 버전이면 기존 Release 의 파일이 바뀐다)
- 버전은 `src-tauri/tauri.conf.json` 의 `version`
- 코드 서명 인증서가 없어서 처음 실행할 때 SmartScreen 경고가 뜬다 ("추가 정보 → 실행"). 회원 안내에 적어둔다

## 개발 (화면만, 브라우저에서)
롤 클라이언트·Rust 없이 모의 데이터로 화면을 본다. 창 3개.
```powershell
npm run server:dev            # 서버 (server/.dev.vars 에 DEV_LOGIN=1)
npm run desktop:bridge        # 모의 클라이언트 :5199
npm run desktop:dev           # 화면 http://127.0.0.1:5174
```
장면 바꾸기: `Invoke-RestMethod -Method Post http://127.0.0.1:5199/scene -Body '{"scene":"in-game"}'` (`champ-select` / `in-game` / `idle` / `no-client`)

## 개발 (실제 앱, Windows)
Rust(rustup)와 WebView2 가 필요하다.
```powershell
$env:PRISM_SERVER = "http://127.0.0.1:8787"; $env:PRISM_DEV_LOGIN = "1"
npm run tauri -w @prism/desktop -- dev
```
`PRISM_DEV_LOGIN` 은 빌드 시점에 들어가는 개발용 스위치다. **배포 빌드에는 절대 넣지 않는다.**

## 알려진 한계 — 실제 롤 클라이언트로 아직 확인하지 못함
설정 → **확인용 정보 복사**로 받은 내용(다른 플레이어 이름은 지워짐)으로 확인한다.
- 아수라장 증강 필드 (`playerAugment1~N` 으로 추정)와 그 ID 가 게임 파일의 `AugmentPlatformId` 와 같은지 (가이드·실전 승률 연결)
- 챔프 선택 세션의 팀원 `puuid` (케미 표시)
- 다른 회원 PUUID 로 전적 조회가 되는지 (회원 대신 기록)
- 대기석 필드 이름 (`benchChampions` / `benchChampionIds`)
- 롤 클라이언트 프로세스의 실행 파일 위치·명령줄을 일반 권한으로 읽을 수 있는지 (설치 폴더 lockfile → 명령줄 순서로 접속 정보를 찾는다)
