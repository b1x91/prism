# Prism 앱 (v0.4)

롤 클라이언트 옆에 켜두는 동반 앱. 혼자 써도 쓸모 있고, Prism 회원이면 모임 기능이 열린다.

## 화면
| 탭 | 혼자서도 | Prism 로그인 후 |
|---|---|---|
| 홈 | 최근 10판, 최근 판, 자주 고른 증강. 챔프 선택 중 팀 구성(AP/AD·앞라인·CC)과 **대기석 밸런스 추천**, 챔피언별 **어울리는 증강**. 게임 중에는 맨 위에 **내 챔피언 증강 가이드** | 같은 팀 회원과의 **케미**(같이 한 판 승률), 챔피언별 모임 승률·모임 인기 증강·장인·대표 팁 |
| 증강 | **챔피언별 가이드**(프리즘·골드·실버별 어울리는 증강과 이유), **증강 도감**(아수라장 증강 전체, 한국어 설명·검색), 내 증강 기록 | 가이드에 **Prism 실전 승률**(이 챔피언으로 / 모임 전체) |
| 도감 | 전체 챔피언 중 해본 챔피언과 승률 | 챔피언을 누르면 모임 기록, 장인, **회원 한 줄 팁** (쓰기·공감) |
| 모임 | 디스코드·카카오톡 바로가기 | **한 줄 생각**(방명록), 기록(최다 킬·가장 긴 판·이달 최다 출전·도감 1위·최고 승률), 같이 하면 이기는 사람, 새 팁, 최근 모임 판 |
| 설정 | 모임 채널, 진단 파일 저장 | 닉네임, 수집 동의·철회, 업로드 상태, 로그아웃 |

혼자 쓰는 기능은 최근 100판(LCU) 기준이다.

## 증강 데이터 (`app/data/`)
- `npm run data:mayhem` 으로 만든다. 출처는 CommunityDragon(롤 게임 파일 공개 미러)의 아수라장 모드 파일과 한국어 문구표. 패치마다 다시 돌린다
- **어울림**은 사람이 붙인 증강 태그(`scripts/mayhem/augment-tags.ts`)와 챔피언 역할·피해 유형·스킬 설명을 맞춘 것이다. 증강 자체의 세기는 아니다. 세기는 Prism 실전 승률이 맡는다
- 새 증강이 생기면 스크립트가 "궁합 태그가 없는 증강"을 출력한다 → 태그 표에 한 줄 추가
- 게임 중에만 계산되는 수치(주문력 비례 피해 등)는 설명에서 "일정량"으로 나온다

## 모임 소통
실시간 대화는 디스코드·카카오톡이 맡는다. 앱에는 바로가기(사이드바·모바일 상단·모임 화면)와 짧은 방명록 "한 줄 생각"(60자)만 둔다.
주소는 서버 설정 `DISCORD_INVITE_URL`, `KAKAO_OPENCHAT_URL` (`server/wrangler.toml`). 비어 있으면 버튼이 숨는다.

## 지키는 것
- LCU 는 GET(읽기)만. 초대·수락·픽 같은 조작 요청은 코드에 없다 (`app/lcu.ts`)
- 게임 중에는 롤에 아무 요청도 하지 않는다. OS 프로세스 목록으로 게임 실행 여부만 본다
- **로그인 + 수집 동의 전에는 서버로 아무것도 보내지 않는다**
- 동의하면: 내 아수라장 판(10명 상세)을 올리고, 한가할 때(대기·로비) 30분에 1번 동의한 다른 회원의 최근 20판을 대신 올린다. 챔프 선택이나 게임이 시작되면 즉시 멈춘다
- 서버는 비회원 참가자 정보를 저장하지 않는다 (팀 합계 계산에만 쓰고 버린다)
- 로그인 토큰은 `%USERPROFILE%\.prism\config.json` 에만 저장한다. 화면(브라우저)에는 내보내지 않는다

## 확인 간격
| 상황 | 간격 | 하는 일 |
|---|---|---|
| 클라이언트 꺼짐 | 20초 | OS 프로세스 확인만 |
| 대기·로비·매칭 | 15초 | 게임 단계 1회 조회 |
| 챔프 선택 | 5초 | 게임 단계 + 챔프 선택 정보. 구성이 바뀔 때만 서버에 질의 |
| 게임 중 | 30초 | OS 프로세스 확인만 (롤 요청 없음) |
| 게임 직후 3분 | 30초 | 새 판이 뜰 때까지 전적 재조회 |

## 실행 (Windows, PowerShell 7, Node.js 22 이상)

### 1. 받기 (처음 1번)
```powershell
git clone https://github.com/b1x91/prism.git
cd prism
git checkout claude/new-session-18cxmx
npm install
```

### 2-A. 혼자 쓰는 기능만 (가장 간단)
```powershell
npm run app
```
브라우저가 `http://127.0.0.1:5199` 로 열린다. 홈·증강·도감과 챔프 선택 카드(내 기록 기준)가 동작한다.

### 2-B. 모임 기능까지 (서버를 내 PC 에서)
디스코드·Cloudflare 설정 없이, 서버를 내 PC 에 띄우고 가짜 로그인으로 들어간다. 창 2개.
```powershell
# 창 1: 서버 (처음 1번만 앞의 두 줄)
Copy-Item server/.dev.vars.example server/.dev.vars
npm run server:migrate:local
npm run server:dev
```
```powershell
# 창 2: 앱
$env:PRISM_SERVER = "http://127.0.0.1:8787"
$env:PRISM_DEV_LOGIN = "1"
$env:PRISM_DEV_NAME = "하제"
npm run app
```
설정 탭 → 로그인 → 수집 동의를 누르면 내 판이 내 PC 의 서버에 올라가고, 모임·한 줄 생각·팁·증강 실전 승률이 열린다. 회원이 나 혼자라 케미·장인은 비어 있는 게 정상이다.

### 3. 확인 결과 보내기
챔프 선택을 한 번 거치고, 게임을 1판 마친 뒤(게임 중이 아닐 때) **설정 → 진단 파일 저장**.
`diagnostics/prism-diagnostic-*.json` 이 만들어진다. 다른 사람 닉네임·PUUID 는 지워서 저장한다.
이 파일로 아래 "알려진 한계"의 실측 항목을 확인한다.

서버를 실제로 배포하는 방법은 `docs/deploy-cloudflare.md`.

## 알려진 한계
- 실제 롤 클라이언트로는 테스트하지 못했다 (가짜 LCU 서버로 검증). 특히 아래는 실측 필요
  - 아수라장 증강 필드 (`playerAugment1~N` 으로 추정)
  - 챔프 선택 세션의 팀원 `puuid` (케미 표시에 필요)
  - 다른 회원 PUUID 로 전적 조회가 되는지
  - 아수라장 증강 ID 가 게임 파일의 `AugmentPlatformId` 와 같은지 (가이드·실전 승률 연결에 필요)
  - 챔피언 성향 필드 (`champions/{id}.json` 의 `tacticalInfo.damageType`, `playstyleInfo`) — AP/AD 칩과 팀 밸런스 추천에 필요
  - 대기석 챔피언 썸네일·일러스트 경로
- 아수라장 증강 이름은 클라이언트의 아레나 증강 목록에서 찾는다. 없으면 `#번호`
- 설치 파일·트레이 아이콘·자동 실행은 아직 없다
