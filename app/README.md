# Prism 앱 프로토타입 (v0.1)

롤 클라이언트 옆에 켜두는 동반 앱의 첫 시험판. **써보고 피드백을 주기 위한 용도**다.

## 하는 일
- 내 최근 100판 중 아수라장(2400) 판: 승패 띠, 챔피언, KDA, 아이템, 증강, 딜량
- 챔프 선택 중: 내 챔피언·벤치·우리 팀 챔피언의 **내 아수라장 승률** (추천 데이터는 아직 없음)
- 데이터 확인 표: LCU 가 어떤 필드를 실제로 주는지 (수집기 설계용 검증)
- 진단 파일 저장: 다른 플레이어 이름·PUUID 를 익명화한 원본을 `diagnostics/` 에 저장

## 하지 않는 일
- 서버 전송 없음. 모든 것이 이 PC 안에서만 돈다 (화면은 `127.0.0.1` 전용)
- LCU 는 GET(읽기)만. 초대·수락·픽 같은 조작 요청은 코드에 없다 (`app/lcu.ts`)
- 게임 중에는 롤에 아무 요청도 하지 않는다. OS 프로세스 목록으로 게임 실행 여부만 본다

## 확인 간격
| 상황 | 간격 | 하는 일 |
|---|---|---|
| 클라이언트 꺼짐 | 20초 | OS 프로세스 확인만 |
| 대기·로비·매칭 | 15초 | 게임 단계 1회 조회 |
| 챔프 선택 | 5초 | 게임 단계 + 챔프 선택 정보 조회 |
| 게임 중 | 30초 | OS 프로세스 확인만 (롤 요청 없음) |
| 게임 직후 3분 | 30초 | 새 판이 뜰 때까지 전적 재조회 |

전적 전체 조회는 앱 시작 때와 게임 직후에만 한다.

## 실행 (Windows, PowerShell 7)
Node.js 22 이상 필요.

```powershell
git clone https://github.com/b1x91/prism.git
cd prism
git checkout claude/new-session-18cxmx
npm install
npm run app
```
브라우저가 `http://127.0.0.1:5199` 로 열린다. 롤 클라이언트는 켜기 전이든 후든 상관없다. 종료는 PowerShell 창에서 `Ctrl+C`.

## 써보고 알려줄 것
1. **데이터 확인 표** 화면 (특히 "증강" 칸이 0/N 인지)
2. 챔프 선택 화면이 제대로 뜨는지
3. 가능하면 **진단 파일 저장** 후 그 파일 (`diagnostics/prism-diagnostic-*.json`)

## 알려진 한계
- 실제 롤 클라이언트로는 테스트하지 못했다 (개발 환경이 리눅스). LCU 필드 이름은 추정이고 가짜 LCU 서버로만 검증했다
- 아수라장 증강 이름은 클라이언트의 아레나 증강 목록에서 찾는다. 없으면 `#번호`로 표시된다
- 설치 파일·트레이 아이콘·자동 실행은 아직 없다
