랭킹 무대 시안 — 바닥에서 솟는 유리 카드

카드 아래 빈 칸을 없애고 챔프 그림이 카드를 끝까지 채웁니다. 카드는 무대 바닥에서 솟아올라요.

  • 움직임 (약 2초, 1시간에 한 번): 바닥에 빛이 고이고 → 2위 · 3위 · 1위 순으로 카드가 바닥에서 솟고 → 순위 문장이 내려앉고 → 점수가 차오르고 → 1위 카드에 빛 한 줄기.
  • 세 카드는 같은 비율(가로 2 : 세로 3). 1위는 같은 모양을 그대로 크게 키웠어요.
  • 카드 안: 대표 스킨 그림이 위에서 아래까지, 아래쪽만 어둡게 깔아 이름·점수가 읽히게.
  • 동작 줄이기 설정이면 처음부터 완성된 무대.
