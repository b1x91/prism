롤 닉 복사 — 시안 3개

아카이브 '지금 접속' 줄 기준. 마우스를 올리고 눌러 보세요 (실제로 복사됩니다).

시안 A

올리면 나타나는 알약

평소엔 단추가 없고, 줄에 마우스를 올리면 챔프 그림 자리에 '닉 복사' 알약이 밀려 나옵니다. 누르면 초록 '복사됨'. 가장 조용하지만 기능이 숨어 있습니다.

휴대폰: 줄을 길게 누르면 알약이 나타남

시안 B · 추천

이름 옆 태그 칩

이름 옆에 흐린 '#KR1' 태그를 늘 보여 주고, 태그를 누르면 이름#태그 전체가 복사됩니다. 따로 단추 칸이 없어 줄이 넓고, 무엇을 복사하는지 바로 보입니다.

올리면 태그 옆에 작은 복사 표시, 누르면 '✓ 복사됨'으로 1.4초

시안 C

더 보기 메뉴

줄 끝 '⋯'을 누르면 작은 메뉴: 롤 닉 복사(닉 미리 보기) · 회원 페이지. 나중에 기능(초대 링크 등)이 늘어도 자리가 그대로입니다. 한 번 더 눌러야 합니다.

메뉴 바깥을 누르거나 Esc 로 닫힘
