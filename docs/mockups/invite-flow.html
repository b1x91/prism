초대 링크로 들어온 사람이 멤버가 되기까지

초대 링크를 연 사람이 우리가 어떤 모임인지 보고, '가입하고 싶어요'로 신청한 뒤 면접방 오픈카톡에서 운영진 두 명과 이야기하고, 확정되면 톡방·디스코드로 들어오는 흐름입니다. 기획을 먼저 보고 시안 셋을 비교해 주세요. 시안 안의 단추·체크는 실제로 눌러 볼 수 있어요.

기획 시안 DB + C 시안 A초대장 시안 B둘러보기 시안 C무대 운영 화면공통

목표

초대 링크는 '누가 누구를 불렀다'는 기록이 아니라 Prism의 첫인상이다. 링크를 연 사람은 1분 안에 우리가 어떤 모임인지 알고, 규칙에 동의한 사람만 신청하고, 신청한 사람은 다음에 무엇을 해야 하는지 절대 헷갈리지 않는다.

  • 링크는 누구나 퍼 나를 수 있다. 문은 링크가 아니라 면접이다.
  • 신청자는 로그인·디스코드 계정 없이도 신청할 수 있다. (디스코드는 확정 뒤에)
  • 운영진 두 명이 같은 화면에서 같은 사람을 보고, 둘 다 확인해야 확정된다.
  • 확정된 사람이 나중에 로그인하면 '승인 대기'를 다시 거치지 않는다. 추천인·초대 보너스도 저절로.

신청자초대 페이지

누가 불렀는지 → 어떤 모임(30대 이상 · 매일 밤 증바람 · 지인 추천제) → 어떤 공간(디스코드 · 카카오톡 · Prism 앱/웹) → 규칙 7개 → 가입 과정 4단계. 끝에 '가입하고 싶어요'.

신청자규칙 동의 + 신청서 (1분)

롤 이름#태그 · 카카오톡 오픈프로필 이름 · 30대 이상 확인 · 주로 접속하는 시간 · 한마디(선택). 전화번호·실명은 받지 않는다.

Prism대기 목록에 등록 + 면접 번호 발급

예: P-427. 같은 롤 이름의 신청이 이미 있으면 그 신청으로 안내. 봇이 운영진 두 명에게 DM, 운영 메뉴에 빨간 점.

신청자면접방 오픈카톡 들어가기

완료 화면에서만 면접방 주소(와 비밀번호)를 보여 준다. 첫 인사 문구 'P-427 · 롤닉 · ○○님 초대'를 한 번에 복사. 이 기기에는 내 신청 상태 페이지가 남는다.

운영진 2명면접 · 2인 확인

운영 › 가입 신청에서 '면접 시작' → 이야기 → 두 사람이 각각 '확정'을 눌러야 확정. 보류·거절은 한 명이 해도 되고 메모를 남긴다.

운영진톡방·디스코드 초대 → '초대함' 표시

본 톡방(PRSM)과 디스코드 초대를 보낸 뒤 '초대함'. 신청자 상태 페이지가 '환영해요 · 디스코드 들어가기 → 로그인'으로 바뀐다.

Prism로그인하면 신청서와 자동 연결

롤 계정을 연결할 때 신청서의 롤 이름과 맞으면 바로 준회원 승인 + 추천인 = 초대한 멤버 + 초대 보너스 300. 안 맞으면 운영 화면에 '신청서와 연결' 단추.

신청→ 면접 중→ 확정→ 초대함→ 가입 완료
곁가지보류거절연락 없음 (3일)정리됨 (14일)

상태가 바뀔 때마다 누가 언제 바꿨는지 남는다. 두 운영진이 동시에 눌러도 먼저 저장된 쪽이 이기고, 늦은 쪽에는 '방금 ○○님이 바꿨어요'가 뜬다.

막히지 않게 — 예외와 처리

상황처리
링크가 큰 커뮤니티에 퍼짐신청은 대기일 뿐이라 문제없다. 초대 코드 하나당 하루 신청 10건까지, 넘으면 '잠시 뒤에 다시'. 운영 화면에 코드별 신청 수.
초대한 사람이 아직 승인 전이거나 코드가 틀림소개 페이지는 그대로 보여 주고 '추천인 없음'으로 신청. 운영진이 면접에서 추천인을 고를 수 있다.
같은 사람이 두 번 신청롤 이름 기준 한 건. 두 번째에는 '이미 신청했어요 · P-427'과 면접방 단추.
이미 멤버로그인 상태면 '이미 Prism 멤버예요' + 친구 초대 링크. 신청 단추 없음.
신청 뒤 면접방에 안 들어옴3일 뒤 '연락 없음' 표시, 14일 뒤 신청서 자동 정리. 상태 페이지에는 '면접방에서 기다리고 있어요'와 단추를 계속.
카톡 이름이 신청서와 다름면접 번호로 찾는다. 첫 인사 문구에 번호가 들어 있다.
면접방 주소·비밀번호를 바꿈운영 화면 한 곳에서 바꾼다. 이미 신청한 사람의 상태 페이지도 새 주소를 보여 준다.
롤 이름 오타운영진이 면접에서 고칠 수 있다. 로그인 뒤 연결이 안 되면 일반 승인 대기로 들어오고 운영 화면에 '신청서와 연결'.
거절상태 페이지: '이번에는 함께하기 어려워요. 찾아와 주셔서 고마워요.' 30일 뒤 삭제, 그동안 같은 롤 이름 재신청 불가.
봇 DM이 안 감운영 메뉴 빨간 점(처리할 신청 수)이 늘 함께 켜진다.
인터넷 없이 / 앱이 없는 사람전부 웹(휴대폰)에서 끝난다. 앱 설치는 가입 뒤 안내.

저장하는 것

  • 신청서: 롤 이름#태그 · 카톡 오픈프로필 이름 · 시간대 · 한마디 · 초대 코드 · 면접 번호 · 상태와 바꾼 기록 · 운영진 메모
  • 받지 않는 것: 전화번호 · 실명 · 생년월일 (30대 이상은 체크 하나)
  • 지우는 때: 거절·정리 30일 뒤, 가입 완료되면 신청서는 회원 기록으로 옮기고 지움. 개인정보 처리방침에 함께 적는다.

만들 것

  • 웹: 초대 페이지(/i/:code 개편) · 신청서 · 완료 · 내 신청 상태(/apply/:토큰)
  • 서버: applications 표 · 공개 신청/상태 주소(하루 상한·중복 확인) · 운영 신청 목록/상태 바꾸기 · 로그인 때 자동 연결
  • 운영: 운영 › 가입 신청 탭(칸 넷 보드) · 면접방 주소 설정 · 봇 DM 카드 · 빨간 점에 신청 수
  • 앱: 바뀌는 것 없음 (운영 화면은 공용이라 앱 운영 메뉴에도 같이)

신청자가 보는 4단계

  1. Prism 둘러보고 신청
  2. 면접방에서 운영진과 이야기
  3. 톡방·디스코드 초대 받기
  4. 디스코드로 로그인하면 끝

정해 주셔야 할 것

  1. 면접방 오픈카톡 주소 (비밀번호를 걸지)
  2. 확정에 두 명이 꼭 필요한지 (기본: 둘 다)
  3. 나이: 체크 하나로 충분한지
  4. 확정 뒤 초대 순서: 톡방 먼저 / 디스코드 먼저
  5. 시안 A·B·C 중 하나 (섞어도 좋아요)

지금과 달라지는 점

  • 예전: 링크 → 바로 디스코드 가입 → 로그인 → 승인 대기
  • 바뀐 뒤: 링크 → 소개·규칙 → 신청 → 면접 → 확정 → 로그인하면 바로 준회원

시안 D · 무대 위 둘러보기 (B + C)
