롤 계정 연결 시안

앱 설정의 '롤 계정' 칸 세 가지입니다. 상황은 같습니다 — 메인 Haze#KR18 에 부계정 하나가 연결돼 있고, 지금 롤에는 연결 안 된 세 번째 계정으로 로그인돼 있어요. 모두 눌러서 메인 바꾸기 · 빼기 · 추가를 해 볼 수 있습니다.

시안 A

계정 슬롯

다섯 칸을 늘 보여 줘서 '몇 개까지, 몇 개 찼는지'가 그림으로 읽힙니다. 지금 롤에 로그인한 계정은 빈 칸에 미리 들어와 있어 누르기만 하면 돼요.

  • 메인 칸만 파란 테두리 · 왕관
  • 칸에 마우스를 올리면 ⋯ 메뉴 (메인으로 · 빼기)
  • 장점: 수집하는 느낌, 남은 자리가 바로 보임
시안 B

메인 무대

메인 계정을 어두운 무대 위에 크게 — 'Prism 이름이 이 계정을 따른다'는 게 한눈에. 부계정은 아래 가벼운 줄, 지금 로그인한 새 계정은 맨 위 초록 알림으로 먼저 물어봅니다.

  • 무대 위 내 얼굴 = 회원 페이지와 같은 결
  • 부계정 줄: 메인으로 · 빼기
  • 장점: 메인과 부계정의 차이가 가장 분명함
시안 C

고르는 목록

설정 앱처럼 한 묶음의 목록. 줄을 누르면 그 계정이 메인 — 동그라미 하나로 메인을 고르니 따로 배울 게 없습니다. 빼기는 오른쪽 ×, 한 번 더 확인.

  • 추가할 계정은 목록 맨 아래 파란 줄
  • 가장 조용하고 촘촘함 — 다른 설정 칸과 잘 어울림
  • 장점: 누르는 곳이 적고 실수가 적음
