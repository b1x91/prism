# 디스코드 가입 체크리스트 (규칙 화면에 붙여 넣는 글)

디스코드 서버 설정의 규칙 화면(가입 조건 심사)에 아래 항목을 한 줄씩 넣는다.
새 멤버는 모든 항목에 동의해야 채팅을 시작할 수 있다. 내용은 소식 고정 공지 'Prism 가입 안내 및 운영 수칙'과 같게 유지한다.

## 서버 소개 (규칙 화면 위 설명)

Prism은 아수라장 칼바람을 함께 즐기는 모임입니다. 오래 즐겁게 함께할 수 있도록 아래 항목을 확인하고 동의해 주세요.

## 규칙 항목

1. 아는 멤버의 추천으로 가입합니다. (초기 지인 추천제)
2. 디스코드 서버와 카카오톡 오픈채팅에 함께 참여합니다.
3. Windows PC에 Prism 앱을 설치합니다. (przm.web.app/download)
4. 카카오톡 오픈프로필은 본인 사진으로 설정합니다.
5. 연 2회 멤버 정리가 있으며, 그때까지 톡방 멤버와 함께한 판이 없으면 정리 대상이 되는 것에 동의합니다.
6. 같은 민원이 반복되면 경고를 받을 수 있음에 동의합니다.
7. Prism 앱이 모은 아수라장 전적이 Prism 회원에게 보이는 것에 동의합니다. (przm.web.app/privacy)
